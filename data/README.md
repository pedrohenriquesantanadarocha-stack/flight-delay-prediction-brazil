# Data layers

Generated by the pipeline; everything here except this file is git-ignored.

```
01_raw/           ANAC CSVs as downloaded (temporary)
02_intermediate/  vra/vra_YYYY_MM.parquet
03_primary/       flights/flights_YYYY_MM.parquet, weather/weather_YYYY.parquet (+ _airports.json)
04_feature/       flights/features_YYYY_MM_thr{threshold}.parquet
05_model_input/   samples/sample_YYYY_MM_thr{threshold}_n{cap}_rs{seed}.parquet
07_model_output/  <run>/test_predictions.parquet
08_reporting/     <run>/  tables, figures, tabelas_modelagem.tex, summary.json
```

`<run>` is `thr{threshold}_n{cap}_rs{seed}_{split}_{years}`, e.g. `thr30_n20000_rs42_by_day_2024-2025`.
