# flight-delay-prediction-brazil
Predicting 30+ minute departure delays in Brazilian commercial aviation using ANAC flight data (VRA, 2024–2025) and daily weather (GSOD/NOAA). Compares Logistic Regression, Decision Tree, Random Forest, and XGBoost on ~480K flights; Random Forest performs best (ROC-AUC 0.71, PR-AUC 0.255). Includes paper and code.
